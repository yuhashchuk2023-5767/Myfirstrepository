# AI Agent “Transport Navigator”

 Інформація про студента

Проєкт: Варіант 8 — Розклад громадського транспорту

 Ідея проєкту

Створено простого AI-агента, який працює як довідник з громадського транспорту.
Він дозволяє дізнатися інформацію про автобусні та залізничні маршрути, використовуючи об’єктно-орієнтований підхід.

 Функціонал системи

Агент виконує такі задачі:

приймає запит користувача (наприклад “Маршрут 1”)
знаходить відповідний маршрут у системі
повертає детальний розклад
форматує відповідь у зрозумілому вигляді

 Логіка AI-агента

Агент працює за таким принципом:

приймає текст користувача
визначає номер маршруту
викликає tool-функцію
формує відповідь
додає пояснення у природній мові
 Приклади використання
🔹 Запит:

🔹 Відповідь:
