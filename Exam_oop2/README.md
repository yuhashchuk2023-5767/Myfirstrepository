Проєкт: Варіант 8 — Розклад громадського транспорту

💡 Ідея проєкту

У межах проєкту розроблено простого AI-агента, який виконує роль інформаційного довідника з громадського транспорту.

Система дозволяє отримувати інформацію про автобусні та залізничні маршрути, використовуючи принципи об’єктно-орієнтованого програмування (ООП).

⚙️ Функціонал системи

Розроблений агент виконує такі функції:

приймає запит користувача (наприклад: “Маршрут 11”)
виконує пошук відповідного маршруту в системі
повертає структуровану інформацію про розклад
формує зрозумілу відповідь для користувача

🔷 Наслідування

Реалізовано два класи-нащадки:

🚌 Bus

Додаткові дані:

🚆 Train

Додаткові дані:

🔷 Поліморфізм

Кожен клас реалізує метод:

get_schedule()

але повертає різну структуру даних залежно від типу транспорту (автобус або потяг).

🔷 Інкапсуляція

Клас:

Schedule

Містить приватний атрибут:

__routes

та методи:

додавання маршрутів
пошук маршруту
отримання списку маршрутів

📌 Назва:

🎯 Призначення:

Функція:

повертає структуровану інформацію
